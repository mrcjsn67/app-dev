# Stranger Things

> A nostalgic sci-fi horror series set in the 1980s.

## Main Characters
- **Eleven** - The girl with psychokinetic powers
- **Mike Wheeler** - The loyal leader of the group
- **Dustin Henderson** - The clever and funny one

## Quick Facts
1. Released on Netflix
2. Created by the Duffer Brothers
3. Set in the fictional town of *Hawkins, Indiana*
